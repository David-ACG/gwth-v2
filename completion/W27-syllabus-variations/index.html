Four ways the syllabus page could look

You asked for three variations to pick from, because the page is a wall of same-coloured text with nowhere for the eye to land. Nothing here is live. The current design is option 0 and is a real option: if none of the three earns its keep, we keep what we have.

"At the moment it seems like a lot of text all with the same colours so my brain does not know where to look. Please add some colour to differentiate different sections. Don't change the text, just use design to make it more readable."

What is the same in all three

Every option keeps the FDE journal register: Source Serif 4, JetBrains Mono for metadata, paper grounds, square corners, hairlines, no gradients, no pill badges. Every colour is a register colour (teal, moss, rust, ochre) used as a rule, a band or a wash, never as text, so nothing depends on colour to be readable and both themes pass contrast.

All three also do three things the current page does not, so that the comparison is only about the colour mechanism:

  • The week heading steps up in size and gets real space above it, so it stops looking like another lesson row.
  • The 26 repetitions of "45m" and "Not started" drop to a lighter weight in one fixed right-hand column, so the lesson titles carry the page. Every word is still there.
  • Months 2 and 3, which are locked and nearly empty, recede instead of shouting as loudly as Month 1.

What did not change

Not one word. Same titles, same counts, same headings, same capstone copy. Checked by rendering each option and diffing its visible text against the live page: all four are byte-identical (text-live.txt vs text-v-a.txt and friends, in this folder).

Option 0

No change

Current design

What it does

Ink on paper, hairline rules, everything at one weight. Structure is carried entirely by two type sizes and a horizontal line, and colour is absent apart from the ochre on hover.

What it costs

It is calm and unmistakably the house style, and it will never date. But at 26 lessons the eye has no landmark: week headings are only a little larger than lesson titles, and the repeated status column competes with the titles for attention. That is the thing you noticed.

Option A

Restrained

Colour spine

What it does

Each week is claimed by a 3px vertical rule running down its left edge, in a teal, rust, moss, ochre rotation, with the lessons indented inside it. Each month gets a thick coloured rule across the top; the capstone gets an ochre spine of its own. Colour is a margin note, not a surface.

What it costs

It is the quietest of the three and the safest with the register: it adds no new surfaces at all. The cost is exactly that quietness. From across a room the page still reads as one grey column, and on a phone the spine is 3px of colour against a full screen of text. If you want the demo audience to see structure at a glance, this may be too polite.

Option B

Bold

Chapter blocks

What it does

Each month becomes a paper panel, and each week heading becomes a full-width solid colour band with the heading reversed out of it: teal, bronze, moss, ochre. Four unmistakable landmarks down the page. This is the register's own colour-block card top, used at section scale.

What it costs

The loudest option, and the one furthest from "a careful journal". Four saturated bars give the page a product feel that the rest of the site does not have yet, so it would want repeating elsewhere or it will look like a one-off. Bronze is a deepened rust, because cream on the register's rust is 3.3:1 and fails contrast; that is one derived shade, disclosed.

Open option B

Option C

Middle

Tinted fields

What it does

Each week sits in its own softly tinted panel, a wash of that week's colour at about a tenth strength, capped by a 4px solid rule in the same colour. The capstone gets an ochre field so it stops looking like more lessons. You group the page by region before you read a word, and the text is still ink on near-paper throughout.

What it costs

The register says colour arrives as solid blocks. A flat tint is not a gradient, but it is softer than the rule describes, so this option is a deliberate stretch and would need writing into the bible if you pick it. The washes are also the first thing a bad screen or a projector will flatten: on a washed-out beamer the fields may vanish and you are left with option A.

Open option C

The recommendation, for what it is worth

C, tinted fields for Monday. It is the only one where the four weeks read as four things before you focus on anything, which is your actual complaint, and it does it without turning a journal into a dashboard. B is a better answer to "make it obvious" and a worse answer to "keep it GWTH". A is the safest and the least likely to fix the problem you raised.

If you want one change to C: it is the option most sensitive to a bad screen. If the CIPD demo is going through Teams screen-share on someone else's monitor, pick B instead and accept the loudness for a day.
