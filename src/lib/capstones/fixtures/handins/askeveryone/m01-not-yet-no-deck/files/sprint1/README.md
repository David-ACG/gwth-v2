# Sprint 1: interview prototype

Preview: https://askeveryone-sprint1.vercel.app (test organisation only)

A respondent opens the interview, ticks the consent box, and types answers to
six questions. Each answer is saved to the transcripts table in Neon
(transcripts_export.json shows my test row).

Reflection: typing works. I did not get the microphone working in time, and
there is no invitation link yet, so anyone with the URL can start.
