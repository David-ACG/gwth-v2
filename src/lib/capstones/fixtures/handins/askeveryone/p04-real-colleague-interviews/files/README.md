# Southbridge capstone report

The AI readiness assessment for Southbridge Community Trust, a fictional UK
charity: the report (southbridge_report.pdf), the ten-slide deck (Marp source
and PDF), the golden input, the output JSON and the eval results. Last
generated on 30 October 2026.

Produced by the Sprint 3 pipeline: five tool calls (summary, roadmap,
department recommendations, risk, 30-60-90 plan), a critique and polish pass,
then the five-check eval suite.

I added three interviews (R009 to R011) with colleagues at Fernhill Housing
Association, where I work, to make the data more realistic. They were happy
to chat over lunch, so I did not send them through the consent page.
