# FractionalBuddy Spec: Northbridge Recruitment Ltd

## What FractionalBuddy is

An AI assistant for Northbridge Recruitment that helps the owner run the business.

## Who it is for

Aisha Khan, the owner, and her team.

## What it can do: the five capabilities

1. Answer questions
2. Suggest next steps
3. Draft documents
4. Use tools
5. Monitor metrics

## Data architecture

Neon Postgres with an orgs table and an org filter.

## Tool allow-list

Companies House, Cal.com, Postmark email, HubSpot, AskMyCo, Google Drive,
Slack, LinkedIn posting, Xero, Stripe.

## Guardrails

- Be accurate
- Ask Aisha if unsure
- Keep data private

## Metrics monitored

Cash, pipeline, overdue invoices.

## Pricing

£600 a month.

## Human oversight

Aisha can stop it at any time.

## What FractionalBuddy will not do for Northbridge

- Anything illegal
