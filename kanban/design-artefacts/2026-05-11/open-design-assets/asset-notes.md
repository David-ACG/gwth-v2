# GWTH Open Design Logo Assets

Use these files as locked logo references for Open Design:

- `gwth-logo-locked-light.svg` uses wordmark `#22301f` and accent `#a94c2e`.
- `gwth-logo-locked-dark.svg` uses wordmark `#edeae6` and accent `#a94c2e`.

The geometry is copied from the canonical `public/logo-gwth.svg`, but the colours are corrected to match the live React logo variables in `src/app/globals.css`.

Do not ask Open Design to redraw, reinterpret, simplify, or recolour the logo. The design work should explore surrounding UI, palette, typography, layout, mood, and interaction patterns while treating the logo as a fixed brand asset.

The older black/mint SVG and PNG exports can be used only as archive/history references. They should not be attached to the main Open Design prompt because they may pull the generation back toward the old palette.
