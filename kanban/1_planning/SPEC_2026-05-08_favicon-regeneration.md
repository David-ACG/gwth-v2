## Target glyph

- **Use the G-mark only**, not the full `GWTH.ai` wordmark. The wordmark
  becomes illegible below ~64 px. The G with the angled arrow inside is
  the recognisable mark.
- Refer to `src/components/marketing/redesign/logo-gwth.tsx` for the
  authoritative SVG geometry.

## Locked colours (2026-04-30)

| Role | Light mode | Dark mode | CSS var |
|------|-----------|-----------|---------|
| Wordmark / glyph fill | `#22301f` (deep forest) | `#edeae6` (warm off-white) | `--logo-wordmark` |
| Accent (arrow + dots on i, a) | `#d4a73c` (bright gold) | `#d4a73c` (same) | `--logo-accent` |

The favicon uses the G-mark only, so only **wordmark** + **accent**
matter. The glyph silhouette is the wordmark colour; the angled arrow
inside the G is the accent.

The favicon should adapt to user OS theme via
`@media (prefers-color-scheme: dark)` inside the SVG, the same way the
existing `favicon.svg` does (just with the new colours). The browser tab
strip on macOS and Windows already supports this for SVG favicons.

## Execution path

Pick one — do **not** generate the favicon ad-hoc:

1. **realfavicongenerator.net** — upload a 512×512 PNG of the G-mark in
   `#22301f` and feed it the colour overrides. Toggle "Generate dual SVG
   favicon" with light `#22301f` / dark `#edeae6`. Output: full set
   above.
2. **Claude Design** — only if you specifically want a vector-edited
   result. Note: per persistent memory, Claude Design has a
   logo-redo/SVG-loop failure mode. Lock the geometry to the existing
   `LogoGwth` component first by importing the SVG path data directly.
