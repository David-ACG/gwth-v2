# Lab Ideas — Newsbot Project

> Generated 2026-03-12. Hands-on labs derived from the Newsbot AI news scraper project.

## Month Mapping

- **Month 1** — "From Zero to Building" (AI for Your Life): First builds, basic tools, immediate results
- **Month 2** — "Building Real Apps" (AI for Your Industry): Production-grade patterns, real integrations
- **Month 3** — "Enterprise AI & Multi-Agent Systems" (AI Transformation): Deployment, monitoring, scaling

## Lab Ideas

| # | Lab | Month | Difficulty | Duration | Description |
|---|-----|-------|------------|----------|-------------|
| 1 | Build an RSS Feed Reader | 1 | Beginner | 30 min | Parse 3 RSS feeds, extract titles and dates, print a formatted summary. First exposure to feedparser and async HTTP. |
| 2 | Compare 3 LLM APIs Side-by-Side | 1 | Beginner | 45 min | Send the same prompt to Claude, DeepSeek, and Groq. Compare response quality, speed, and cost. Record results in a table. |
| 3 | Build a URL Deduplicator | 1 | Beginner | 30 min | Normalise URLs (strip UTM params, fragments, trailing slashes) and detect duplicates. Learn about URL anatomy and string processing. |
| 4 | Fuzzy Title Matching with rapidfuzz | 1 | Beginner | 30 min | Compare article titles using fuzzy string matching. Tune the similarity threshold and see how it affects dedup accuracy. |
| 5 | Prompt Engineering Workshop: Get JSON from an LLM | 2 | Intermediate | 45 min | Iteratively refine a prompt until an LLM reliably produces valid JSON with required fields. Handle edge cases and malformed responses. |
| 6 | Build an LLM Provider Switcher | 2 | Intermediate | 60 min | Implement the ABC provider pattern. Create providers for two different LLM APIs and swap them via config without changing app code. |
| 7 | Pydantic Settings from .env Files | 1 | Beginner | 20 min | Use pydantic-settings to load, validate, and type-check configuration from environment variables. Handle missing and invalid values. |
| 8 | Structured Logging Lab | 2 | Intermediate | 30 min | Replace print() with structlog. Add context fields, configure log levels, and output machine-readable JSON logs. |
| 9 | Design a Content Pipeline Database | 2 | Intermediate | 45 min | Design and create PostgreSQL tables for raw articles, processed articles, and subscribers. Add indexes, constraints, and RLS policies. |
| 10 | Mock HTTP Tests with respx | 2 | Intermediate | 45 min | Write pytest tests that mock external HTTP calls. Test success paths, error handling, and timeouts without hitting real servers. |
| 11 | Build a CLI with argparse | 1 | Beginner | 30 min | Create a multi-command CLI tool with subcommands, flags, and help text. Add a --dry-run mode that simulates actions without side effects. |
| 12 | Dockerize a Python App | 3 | Intermediate | 60 min | Write a Dockerfile, build an image, manage env vars with docker-compose, and run the Newsbot scraper in a container. |
| 13 | Build a Telegram Alert Bot | 3 | Intermediate | 45 min | Create a Telegram bot that sends alerts when content quality issues are detected. Handle message formatting and rate limiting. |
| 14 | Newsletter Pipeline: HTML Email + MailerLite | 3 | Advanced | 90 min | Build an end-to-end newsletter: query top articles, render an HTML email template, integrate with MailerLite API, and manage subscribers. |
| 15 | End-to-End News Pipeline | 3 | Advanced | 90 min | Wire together RSS scraping, deduplication, LLM processing, and database publishing into a complete automated pipeline. Run it and verify results. |
