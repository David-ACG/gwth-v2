# Andrej Karpathy — Software 3.0, LLM OS, Vibe Coding

Karpathy (ex-Tesla AI director, ex-OpenAI founding member) is the voice that reframes AI for technically curious beginners who don't yet code. His framings make vibe coding feel inevitable rather than exotic.

## Three framings worth teaching (in order of abstraction)

### 1. English is the new programming language

From a 2023 tweet and reinforced repeatedly since:
> *"The hottest new programming language is English."*

For beginners: if you can describe what you want clearly, you already speak the programming language. This reframes "I can't code" as "I can now code — I've just been calling it writing."

### 2. Software 3.0

From his 2025 talk *"Software Is Changing (Again): Software 3.0":*
- **Software 1.0** — humans write code that computers run.
- **Software 2.0** — humans curate data; neural networks *are* the code.
- **Software 3.0** — humans write natural language prompts; LLMs *interpret and execute*.

The practical implication: *you* are the Software 3.0 programmer. The prompt is the program.

### 3. Vibe coding

Karpathy, February 2025:
> *"There's a new kind of coding I call 'vibe coding,' where you fully give in to the vibes, embrace exponentials, and forget that the code even exists."*

Collins Dictionary: **"vibe coding" Word of the Year 2025.**

In April 2026 Karpathy has evolved the framing ("vibe coding is passé" — he now advocates more intentional prompt/spec writing for real work). For Month 1 beginners the original vibe-coding spirit is still the right entry point.

## The LLM OS metaphor

Karpathy's other durable framing: the LLM is becoming an operating system.
- **Kernel** = the model itself.
- **Peripherals** = tools (search, code execution, file access, browser).
- **Memory** = context window + retrieval.
- **Apps** = agents and workflows built on top.

For Month 1 students this makes Artifacts, Cowork and Custom GPTs feel like using a new type of computer, not like "prompt engineering."

## Why this matters for Month 1

- Breaks the "I'm not technical" identity barrier.
- Positions Claude Artifacts / Lovable as *natural*, not magical.
- Reframes "learning AI" as "learning the new operating system" — gives students a mental permission slip to spend time playing with it.
- Connects the first-build moment in L9 to something bigger than a calculator.
