# Vibe Coding — the 2026 Landscape for Beginners

Research spine for L9 (first app), L10 (bigger tool), L11 (website), L13 (dashboard).

## Origin of the term

Andrej Karpathy, Feb 2025:
> *"There's a new kind of coding I call 'vibe coding,' where you fully give in to the vibes, embrace exponentials, and forget that the code even exists."* — https://x.com/karpathy/status/1886192184808149383

Collins Dictionary: **"vibe coding" Word of the Year 2025.**

## Tool landscape April 2026 (the beginner-facing stack)

| Tool | Strength | Pricing | Use in Month 1 |
|------|----------|---------|----------------|
| **Claude Artifacts** | Zero-setup, now with **20 MB persistent storage per artifact** (2026) | Included in Claude Pro | L9 first build, L13 dashboard |
| **Lovable** | Easiest end-to-end, Supabase-backed auth + DB | Free 5 msg/day; Pro $25 | L10 (stretch), L11 website |
| **Bolt.new** | Fastest prompt-to-deployed app | Token-based from ~$20 | L10/L11 option |
| **v0** | Best for polished Next.js UIs, deploys to Vercel | Free ($5); Pro $20/user | L11 option |
| **Replit Agent** | Full-stack with DB + auth one-click | Core $20–25; heavy users hit $100+ | L10 option; mention only |
| **Google AI Studio (Stitch)** | Vibe-coding mode for exploration | Free tier | Optional exploration |
| **Cursor / Windsurf** | Proper IDEs — name-drop only | Pro $20 | Not in Month 1 |

**The three-layer 2026 workflow** to teach (without scaring beginners):

1. **Explore** — Claude Artifacts or Stitch for 5-minute sketches.
2. **Build** — Lovable or v0 for a real shareable app.
3. **Refine** — Claude Code for the few who want to go deeper (Month 2+).

## Why Claude Artifacts is the Month 1 default

- No setup, no install, no hosting, no API keys.
- Works inside Claude Pro $20/mo (same subscription students have from L3).
- Runs HTML/React/JS in the chat window — students see the result immediately.
- **New in 2026:** persistent storage up to 20 MB per artifact (personal or shared). Calculators remember settings, trackers keep streaks, journals keep entries.
- Export to HTML — forever theirs, forever free, no subscription lock-in.
- Shareable by link to a non-technical friend.

## Why Lovable is the UK-friendly web-app default

- European company (Stockholm), cultural fit for UK learners.
- Supabase auth + DB — you can make a real web app with accounts.
- UK is ~5% of traffic (Similarweb) — UK is Lovable's #2 or #3 non-US market.
- Free tier generous enough for one L11 build.
- Shareable URL that the student can post on LinkedIn.

## What students can build in L9–L13

**L9 (Artifacts, 60 min):**
- Household budget calculator
- Recipe scaler
- UK unit converter (miles→km, £/gallon→£/litre)
- GCSE quiz generator
- Kids' chore tracker
- Council tax / stamp duty calculator
- Gift idea generator for family

**L10 (Artifacts or Lovable, 90 min):**
- Client intake form
- Personal CRM
- Habit tracker with streaks
- Invoice generator
- Meeting-agenda builder with timer

**L11 (Lovable / Bolt / v0, 90 min):**
- Personal portfolio / CV site (published to a URL)
- Landing page for a side business
- Charity / club / event site

**L13 (Artifacts, 90 min):**
- Interactive dashboard from L12's data
- At least three chart types, one filter/tab

## What students should NOT try in Month 1

- Anything with user authentication beyond Lovable's built-in.
- Payment processing.
- Custom API integrations beyond Zapier-mediated ones (L16).
- Production-grade security.
