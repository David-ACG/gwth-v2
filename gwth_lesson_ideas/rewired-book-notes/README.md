# Rewired — book notes

Reference corpus for *Rewired: McKinsey's Playbook on How Leading Companies Win with Technology and AI* (2nd edition, 2026; ISBN 9781394381906), by Lamarre, Smaje, Levin, Singla and Sukharevsky.

Built to feed the GWTH AI course with quotes, frameworks and worked examples. Cross-links to `../rewired-reference-pack/` (McKinsey companion articles) are used rather than duplicating content.

## Structure

- `INDEX.md` — table of contents, capability × chapter matrix, workflow log.
- `SOURCES.md` — what came from where; what was blocked; which claims need verification.
- `glossary.md` — McKinsey-specific terms (digital factory, pods, MLOps, data products, etc.).
- `NN-chapter-slug.md` — one file per chapter. Frontmatter + summary + key concepts + quotes + GWTH notes + cross-links.
- `capabilities/` — one file per Rewired capability, synthesised across chapters.

## House style

UK English throughout. Tight reference prose: no padding, no bullet-heavy exposition when a sentence will do. Quotes blockquoted, always attributed to a Kindle location, and kept under ~25 words by default. Verbatim content is always in blockquotes; paraphrase stays in prose.
