# Month 3 Research — Leading with AI in Companies

*Assembled 2026-04-20. Source material for Month 3 of the GWTH course, which shifts from "building apps with AI" (Months 1–2) to "leading AI transformation in your organisation".*

## Purpose

Month 3 is for participants who have now built several working AI apps. The question changes from *"how do I use AI?"* to *"how do I get my team, department, or company to use AI well?"* That is a leadership, strategy, and org-design problem — not a coding problem.

This folder assembles the best external material on that problem so the GWTH lessons can cite, quote, and frame against it.

## What's in here

Each file is a structured summary of one primary source: key arguments, quotes, statistics, and links back to the original. Files are numbered loosely by how central they are to the Month 3 narrative.

## How to use this for lesson design

Each lesson in [`../MONTH_3_LESSON_IDEAS_2026-04-20.md`](../MONTH_3_LESSON_IDEAS_2026-04-20.md) cites one or more of these files. When you write the lesson material:

1. Read the research file for the lesson's primary source.
2. Pull 1–3 quotable statistics or frames from it.
3. Link back to the original article (every file has a **Sources** section at the bottom).
4. Use the Rewired book notes (`../rewired-book-notes/`) for the principled, longer-shelf-life framing; use the 2026 articles (this folder) for current examples and statistics that make the principles concrete.
