# PLAN: apicompare.net — LLM API Comparison Platform

## Overview

A public website at **apicompare.net** that publishes real-world LLM API comparison data generated by the Newsbot benchmark tool. Serves as:

1. A reference for developers choosing between LLM providers
2. Advertising for GWTH.ai (lesson content source)
3. Lesson content itself (students learn how the site was built)

## Stack

- **Framework:** Next.js 16 (App Router, same as GWTH)
- **Styling:** Tailwind CSS v4 + shadcn/ui
- **Charts:** Recharts for comparison visualisations
- **Data:** Static JSON files generated by Newsbot benchmarks (no database needed initially)
- **Deployment:** Coolify on Hetzner (alongside GWTH and ACG)
- **Domain:** apicompare.net

## Data Flow

```
Newsbot benchmark command
  -> benchmark_results/benchmark_YYYY-MM-DD_HH-MM-SS.json
  -> Copy/push to apicompare-net/data/
  -> Next.js reads JSON at build time (SSG)
  -> Deploy triggers rebuild
```

## Pages

| Route                     | Description                                                                  |
| ------------------------- | ---------------------------------------------------------------------------- |
| `/`                       | Landing page — latest benchmark results, provider ranking table, key metrics |
| `/providers`              | All providers with profiles, pricing, links to sign up                       |
| `/providers/[id]`         | Individual provider detail: all benchmark runs, trends over time             |
| `/benchmarks`             | List of all benchmark runs with date, sample size, providers tested          |
| `/benchmarks/[timestamp]` | Single benchmark run detail with full results table                          |
| `/methodology`            | How benchmarks are run, what metrics mean, sample selection                  |
| `/about`                  | About the project + link to GWTH.ai                                          |

## Key Metrics Displayed

| Metric             | Description                                 |
| ------------------ | ------------------------------------------- |
| Success Rate       | % of API calls that returned a response     |
| JSON Validity      | % of responses that were valid JSON         |
| Field Completeness | % of responses with all required fields     |
| Avg Latency        | Mean response time in milliseconds          |
| Cost per Article   | Estimated USD cost per article processed    |
| Monthly Projection | Estimated monthly cost for 100 articles/day |

## Components

- `ProviderRankingTable` — sortable table with all providers and key metrics
- `BenchmarkChart` — bar/radar chart comparing providers on multiple axes
- `CostCalculator` — interactive tool: "How much would X articles/day cost with each provider?"
- `ProviderCard` — card with logo, name, model, pricing, and benchmark scores
- `LatencyHistogram` — distribution of response times per provider
- `TrendChart` — line chart showing provider performance over multiple benchmark runs
- `GWTHBanner` — CTA banner linking to GWTH.ai course
